## 配樂設計

每個鏡頭都依心情配一組和弦，速度固定在每分鐘 76 拍：

| 心情 | 和弦進行 | 配器 |
|---|---|---|
| 想家 | Am–Dm–E–Am | 鋼琴放慢 |
| 出發與希望 | C–G–Am–F | 鋼琴 |
| 單車與歡樂 | C–G–Am–F | 加入馬林巴琴和沙鈴 |
| 南洋的溫暖 | F–G–Em–Am | — |
| 終章 | 以 Cadd9 收尾 | 疊上鐘聲 |

音效包括海浪、雨聲、機艙聲、相機快門、電話鈴和腳踏車鈴。

## 重新產生影片

```bash
# 1. 字型（不納入版控）：npm i @fontsource/lxgw-wenkai-tc @fontsource/noto-serif-tc，複製到 video/fonts/
# 2. 預覽：在 repo 根目錄 python3 -m http.server，打開 /video/index.html（加 ?t=秒數 可跳到指定時間）
# 3. 輸出：用 Playwright 逐格呼叫 window.renderFrame(f/24) 存成 JPEG，
#    python3 music.py music.wav，再用 ffmpeg 合成 MP4
```
